# Web ページを保存する（Web クリップ）

**管理者が有効にしたときだけ** 使えます（フォルダの画面に「URL を追加」が出ていれば使えます）。

Web ページの URL を渡すと、サーバーがページを取ってきて保存し、タイトル・説明・本文で検索できるようにします。PDF や画像の URL は、そのファイルを普通のファイルとして保存します。

## 保存する

- **フォルダの画面の「URL を追加」**（スマホは右下の **＋**）に URL を入れます
- **ブックマークレット**: 「設定」→「ブックマークレット（見ているページを保存）」の **「docseed に保存」** をブラウザのブックマークバーにドラッグします。保存したいページでそのブックマークを開くと、保存先を選ぶ画面が出ます
  - スマホは、何かのページをブックマークしてから、そのブックマークの URL を設定画面に出ている文字列に書き換えます
  - 保存先を選んで **「保存」** を押すと、「URL を保存しました」の画面が出ます。**「元のページに戻る」** で、保存したページに戻れます（同じページが既に保存されていれば、**「既に保存されている文書を開く」** も出ます）

取ってきている間は一覧に「取得中」と出て、終わると普通のファイルと同じ行になります（種類は「Web クリップ」、サムネイルはページの紹介用の画像）。取れなかったときは「取得に失敗」と出て、「もう一度取得」で試し直せます。

## 保存したページ

- 文書の画面の **「再取得」** で、元のページの今の内容に保存し直せます（前の内容は [過去の版](files.md#過去の版) に残ります）
- **「元のページを開く」** で元の URL を開きます
- 保存した HTML は、安全のため画面には表示しません（ダウンロードはできます）。取り出した本文は「取り出したテキスト」で読めます
- JavaScript で中身を組み立てるページ（SNS など）は、本文が取れないことがあります。そのときもタイトルと説明では探せます

## 取れないページ

安全のため、次のページは取りません。

- 家の中の機器（ルーター・NAS など）や、サーバー自身を指す URL
- 80・443・8080・8443 以外のポートの URL
- 大きすぎるページ（HTML は既定で 5MB まで）、30 秒で取れないページ
- ログインしないと見られないページ（サーバーはあなたのログイン状態を持っていないため）
