# 検索

上の検索欄（`/` キー）か、左のメニューの「検索」から使います。**語が一致する部分** と、**意味が近い部分** の両方を探します（例えば「振込先」で探すと、「お振込み口座」と書かれた請求書も見つかります）。

- 探す対象は、中の文字（写真やスキャンから読み取った文字を含む）と要約です。ファイル名に検索語を含むものは上の方に出ます。タグは `tag:` で絞り込みます
- 自分が見られるファイルだけが出ます（共有されたフォルダの中も含みます）
- 文字の読み取りが終わっていない（「処理待ち」「処理中」の）ファイルと「保存のみ」のファイルは、検索語では見つかりません。種類・タグ・日付・フォルダの絞り込みだけなら一覧に出ます

## 書き方

| 書き方 | 意味 |
|---|---|
| `請求書 振込先` | 空白で区切ると、両方の語を含む部分と、意味が近い部分 |
| `"株式会社サンプル"` | ダブルクォートで囲んだ語を **必ず含む** ものだけ |
| `見積書 -下書き` | `-` を付けた語を含むものを **除く** |
| `type:pdf` | 種類で絞り込む（`pdf`・`image`・`text`・`doc`（文書）・`sheet`（表計算）・`slide`（スライド）・`media`（音声・動画）・`webclip`） |
| `tag:経理` | タグで絞り込む |
| `after:2026-01-01 before:2026-06-30` | 更新日で絞り込む |
| `taken:2026-05`、`taken:2026-05-01..2026-05-10` | 写真の **撮影日** で絞り込む（年・月・日、または `..` で期間） |

- 検索語が無くても、種類・タグ・日付・撮影日・フォルダだけで一覧を出せます（文字の無い写真も撮影日で探せます）
- 検索欄の下の選択欄（種類・タグ・日付、「すべて / 意味が近い / キーワード」）でも同じ絞り込みができます。スマホは「絞り込み」ボタンで開きます
- 選択欄の「フォルダ」で、そのフォルダ（中のフォルダを含む）の中だけを探せます。候補は自分が見られるフォルダ（共有されたフォルダを含む）です。フォルダだけを選ぶと、そのフォルダ（中のフォルダを含む）のファイルが新しい順に並びます
- フォルダを開いているときは、上の **「検索」** ボタンから検索画面に移ると、そのフォルダが「フォルダ」に選ばれた状態になり、中のファイルが並びます。検索語を入れると、その中から探せます
- 「税」「契約」のような **2 文字以下の語** は、意味が近い候補の中でだけ照合します。見つからないときは、少し長い語で探してください
- 画像やスキャンの文書を検索結果から開くと、検索語を含む行が色付きの枠で示されます

## 検索を保存する・履歴

- 検索語を入れる前の検索画面に、**保存した検索** と **最近の検索** が出ます
- 結果の上の **「この検索を保存」** で、よく使う条件（例 `tag:請求書 taken:2026`）に名前を付けて残せます
- 履歴は「履歴をすべて消す」で消せます。どちらも自分だけが見られます

## 関連する文書

文書の画面には、内容が似ている **関連する文書** が 5 件まで出ます（文字の読み取りが終わった文書だけ。自分が見られるものだけ）。

## 質問に答えてもらう

**管理者が有効にしたときだけ** 使えます。

検索画面の **「この質問に、文書をもとに答える」** を押すと、検索で見つかった文書（自分が見られるものだけ）を資料にして答えます。答えの後ろの番号（例「振込先は〇〇銀行 本店です [1]」）が、根拠にした資料です。

- Pi の中の小さな AI が答えるので、出きるまで数十秒かかります。出来た分から表示します
- **誤りがありえます。** 番号の資料を開いて確かめてください
- 資料が見つからないときは答えません
- 文書の中身はサーバーの外に送りません

## 見つからないとき

| 症状 | 確かめること |
|---|---|
| あるはずのファイルが出ない | 一覧の状態が「検索できます」になっているか（[ファイルの状態](basics.md#ファイルの状態)）。「保存のみ」の形式は中の文字では探せません |
| 写真の文字が見つからない | 文書の画面の「取り出したテキスト」で、どう読めたかを確かめる（[読み取りの確認](organize.md#読み取りを確かめる直す)） |
| 関係のない結果が多い | `"…"` で必ず含む語を指定する・`type:` や `tag:` で絞る。続くときは管理者に伝えてください（意味検索の基準を調整できます） |
