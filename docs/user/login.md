# ログインと安全

右上のメニュー →「設定」→ **「セキュリティ（ログイン方法）」** で、自分のログインの方法を決めます。

変更の前に、パスワード（＋確認コード）かパスキーで **もう一度本人確認** をします（「本人確認」の欄。10 分間有効）。

## ログインの方法

| 方法 | 内容 |
|---|---|
| パスワード | 「設定」→「パスワード」で変えられます |
| **パスキー**（おすすめ） | 端末の指紋・顔認証や PIN でログインします。ログイン画面の「パスキーでログイン」か、ユーザー名の欄の自動入力の候補から選びます |
| **確認コード**（2 段階認証） | パスワードの後に、認証アプリ（Google Authenticator・Microsoft Authenticator・1Password など）の 6 桁のコードを入れます |
| 外部アカウント | 管理者が設定していれば、Google などのアカウントでログインできます |

### パスキーを追加する

1. 「パスキー」の欄で名前（例「iPhone」）を入れて「パスキーを追加」
2. 端末の案内に従って、指紋・顔認証・PIN で登録

パスキーが使えないときは、欄に理由が出ます。多いのは **IP アドレス（例 `https://192.168.1.20/`）で開いている** 場合です。パスキーは名前（例 `https://docseed.example.com/`）で開いたときだけ使えます。

### 確認コードを設定する

1. 「確認コード（2 段階認証）」の「確認コードを設定する」
2. 認証アプリで QR コードを読み取り、表示された 6 桁のコードを入れて「有効にする」
3. 表示された **復旧コード（10 個）を控える**。この画面を離れると二度と表示されません

認証アプリの端末をなくしたときは、確認コードの代わりに復旧コードを 1 つずつ使えます（各 1 回）。残りが少なくなったら「復旧コードを作り直す」。

管理者が「確認コードを必須」にしている場合は、設定するまでほかの画面を使えません。

### 外部アカウント（Google など）と結び付ける

1. 一度パスワードなどでログインし、本人確認をする
2. 「外部アカウントの連携」の「Google と連携」（名前は設定によります）

結び付けていないアカウントではログインできません（メールアドレスが同じでも自動では結び付けません）。

### パスワードでのログインを止める

パスキーか外部アカウントを 1 つ以上設定すると、「パスワードでのログイン」の「パスワードでのログインを止める」で、パスワードを使えなくできます。パスワードが漏れてもログインされなくなります。

## ログイン中の端末

「ログイン中の端末」に、ログインしている端末・方法・最終アクセス・IP アドレスが出ます。覚えの無いものがあれば「ほかの端末をすべてログアウト」を押し、パスワードを変えてください。

## ログインできなくなったとき

| 状況 | 対処 |
|---|---|
| パスワードを忘れた・パスキーの端末をなくした・復旧コードも無い | 管理者に「ログイン方法のリセット」を頼んでください。仮のパスワードが発行されます |
| 「試行回数が多すぎます」と出る | 失敗が続くと、そのユーザー名はしばらくロックされます。前にログインしたことのある端末やパスキーからは、ロック中もログインできます |
| パスキーが急に使えなくなった | サーバーの名前（URL）が変わると、登録したパスキーは使えなくなります。パスワード（＋確認コード）でログインして、登録し直してください |

## 気を付けること

- **共有リンク** はリンクを知っている人なら誰でも開けます。期限とパスワードを付け、要らなくなったら無効にしてください（[共有](sharing.md)）
- **API トークン** はアカウントと同じ権限を持ちます。人に渡さないでください（[API トークン](api-tokens.md)）
