# ファイルとフォルダ

## アップロード

フォルダの画面で次のどれかを使います。

- 上の「アップロード」ボタン（`u` キー）
- ファイルやフォルダを画面に **ドラッグ＆ドロップ**（フォルダごと置くと、中の構造も作ります）。フォルダの行の上で離すと、そのフォルダに入ります
- スマホは右下の **＋** →「ファイルをアップロード」か「カメラで撮ってアップロード」

アップロードの進み具合は画面の下に出ます。

- **回線が切れても続きから送ります。** 回線が戻ると自動で再開し、待っている間は「再開まで N 秒」と出ます。ページを読み込み直したときは、同じファイルを選び直すと続きから送ります
- 同じフォルダに同じ名前のファイルがあると、番号を付けた別の名前で保存します。中身を新しくしたいときは、文書の画面の **「新しい版をアップロード」** を使います（[過去の版](#過去の版)）
- 1 ファイルの大きさには上限があります（既定 1GB。管理者が決めます）
- 置いたあと、サーバーが文字を読み取ります。終わると状態が「検索できます」になります（[ファイルの状態](basics.md#ファイルの状態)）

## フォルダの操作

| したいこと | 操作 |
|---|---|
| フォルダを作る | 「新しいフォルダ」（`n` キー） |
| 選ぶ | 行をクリック。`Ctrl`（Mac は `⌘`）+クリックで足す、`Shift`+クリックで範囲。スマホは長押し |
| 開く | ダブルクリック、名前のクリック、`Enter` |
| 移動する | 選んだ行を、フォルダの行・上のパンくず・左の「マイファイル」へドラッグ。または下のバーの「移動」 |
| 名前を変える | 行の「…」→「名前を変更」（`F2`） |
| まとめてダウンロード | フォルダの「ZIP」（2GB まで） |
| このフォルダの中を検索する | フォルダの「検索」。検索画面でこのフォルダが絞り込みに選ばれます（[検索](search.md)） |
| まとめて操作 | 複数を選ぶと下にバーが出ます: 移動・タグ・再処理・要約とタグをやり直す・ゴミ箱に移動（一度に 500 件まで） |

並べ替えは名前・更新日・サイズ。項目が多いフォルダは 100 件ごとにページが分かれます。

## お気に入り・最近開いたファイル

- ファイルやフォルダの画面の **「☆お気に入り」**（`s` キー）で、左のメニューの **「お気に入り」** に並びます
- 同じ画面に **最近開いたファイル**（新しい 20 件）も出ます。履歴はその画面から消せます
- どちらも自分だけが見られます

## 扱えるファイル

どんなファイルでも保存・共有・ダウンロードできます。次の形式は、中の文字を取り出して検索できるようにします。

| 種類 | 形式 | 補足 |
|---|---|---|
| PDF | pdf | 文字の入った PDF はその文字を、スキャンした PDF は画像として読み取ります。ページに貼られた図・写真の中の文字も読みます |
| 画像 | png・jpeg・webp・tiff・gif・bmp・**heic / heif（iPhone の写真）**・avif | 写真の大きさ・撮影日時・カメラも表示します |
| Office | docx・xlsx・pptx（マクロ付きの docm・xlsm・pptm も） | Word は本文と表、Excel はシートごとのセルの値（数式は計算結果）、PowerPoint はスライドごとの図形・表・ノート |
| テキスト | txt・md・csv・json・xml・yaml・html など | |
| Web クリップ | 保存した Web ページ | [Web ページを保存する](webclip.md) |
| 音声・動画 | mp3・m4a・wav・ogg・flac・mp4・webm・mov など | 画面で再生できます。文字起こしは **管理者が有効にしたときだけ**（[下](#音声動画)） |

次は **保存のみ**（文字は取り出しません）です。

- 古い Office の形式（doc・xls・ppt）、パスワード付きのファイル
- Office 文書に貼った画像の中の文字（必要なら PDF に変換してからアップロードしてください）
- 圧縮ファイル（zip など）

### 写真

- 一覧には画像と PDF のサムネイルが出ます
- HEIC など一部のブラウザで表示できない形式や、とても大きな画像は、表示用に変換したものを見せます。**ダウンロードすると原本** が手に入ります
- サムネイルと表示用の画像からは、撮影場所などの情報（EXIF）を消しています。**原本には撮影場所が残ります。** 位置情報を含む写真を共有リンクで渡そうとすると、共有の画面に注意が出ます

### 音声・動画

- mp3・m4a・wav・ogg・flac などの音声と、mp4・webm・mov の動画は、文書の画面と共有ページで再生できます（途中からの再生もできます）
- 動画は、通信量を減らすために軽い再生用の動画を作って再生します（原本はそのまま）
- AVI・WMV・MKV などは、ブラウザで安定して再生できないため、保存とダウンロードだけです
- **管理者が有効にしたときだけ**: 音声と動画を文字起こしして検索できるようにします。Pi の CPU で行うので遅く（1 時間の動画に数時間かかることがあります）、夜の間などに順に進みます。行の先頭に動画の中の時刻（`[00:12:34]`）が付くので、検索結果で場所が分かります。精度は音声の質に左右されるので、大事な記録は元の音声で確かめてください

## 過去の版

次のときは、それまでの中身を **過去の版** として残します。

- 文書の画面の **「新しい版をアップロード」** を使ったとき
- API で同じ名前のファイルを置き換えたとき
- Web クリップを「再取得」したとき

文書の画面の「過去の版」から、ダウンロード・**この版に戻す**・削除ができます。戻したときも今の版が過去の版に残るので、戻したことも取り消せます。

- 残す数は 1 つのファイルにつき新しい 10 件まで（管理者が変えられます）。古いものから消えます
- 過去の版は検索の対象になりません
- ファイルをゴミ箱から完全に削除すると、過去の版も消えます

## ゴミ箱

消したファイルとフォルダはゴミ箱に入ります（`Delete` キー、または行の「…」→「ゴミ箱に移動」）。

- ゴミ箱の中のファイルは、開いて中身を確かめられます
- 「元に戻す」で元の場所に戻ります（フォルダは「フォルダごと元に戻す」）。元のフォルダもゴミ箱にあるときは、マイファイルの直下に戻ります
- 「完全に削除」で、日数を待たずに消せます
- 残す日数は、「設定」→「容量とゴミ箱」で 7・14・30・60・90・180・365 日から選べます（選ばなければ管理者が決めた日数。既定 30 日）。過ぎると完全に削除されます

## 容量

- 左のメニューの下に使っている容量が出ます。上限があればメーターになります
- 「設定」→「容量とゴミ箱」に内訳が出ます
- 数えるのは、自分のフォルダのファイル・ゴミ箱の中・過去の版です。共有したフォルダにほかの人が置いたファイルは、**フォルダの持ち主** の分になります
- 上限を超えるアップロード・新しい版・コピーはできません。古いファイルを消すか、管理者に上限を相談してください
