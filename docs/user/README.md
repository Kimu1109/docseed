# 利用者ガイド

docseed は、ファイルを保存して、中の文字で探せるようにするサーバーです。写真やスキャンした書類の文字も読み取るので、「去年の請求書の振込先」のように中身で探せます。

このガイドは、**docseed を使う人**向けです（サーバーを置く・設定する人は [管理者ガイド](../admin/README.md)）。

## やりたいことから探す

| やりたいこと | ページ |
|---|---|
| 初めて開く・画面の見方・スマホで使う・キーボード操作 | [はじめに](basics.md) |
| ファイルを置く・フォルダを作る・移動する・消す・戻す | [ファイルとフォルダ](files.md) |
| 写真・Office 文書・音声・動画はどう扱われるか | [ファイルとフォルダ](files.md#扱えるファイル) |
| 中身で探す・絞り込む・検索を保存する・質問に答えてもらう | [検索](search.md) |
| タグを付ける・置き場所の候補・要約・読み取りの確認 | [整理する](organize.md) |
| 家族やチームとフォルダを分け合う・外の人にリンクで渡す・送ってもらう | [共有](sharing.md) |
| Web ページを保存する（ブックマークレット） | [Web ページを保存する](webclip.md) |
| パスキー・確認コード・Google でのログイン | [ログインと安全](login.md) |
| スクリプトからファイルを扱う | [API トークン](api-tokens.md) |
| うまく行かない | [困ったとき](faq.md) |

## 画面に出るのに、このガイドに無いとき

管理者が有効にしたときだけ出る機能があります（例: 「URL を追加」、検索画面の「この質問に、文書をもとに答える」、要約）。各ページの「**管理者が有効にしたときだけ**」の印が付いた節を見てください。出てほしい機能が出ないときは、管理者に [管理者ガイドの任意の機能](../admin/README.md#任意の機能) を見てもらってください。
