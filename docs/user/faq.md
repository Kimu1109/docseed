# 困ったとき

| 症状 | 対処 |
|---|---|
| 開くと証明書の警告が出る | サーバーが手元の証明書を使っています。続けてよいかは管理者に確かめてください（管理者向け: [HTTPS の証明書](../admin/https.md)） |
| ファイルがずっと「処理待ち」のまま | 前のファイルの読み取りを待っています。大きな PDF や動画の後は時間がかかります。半日以上変わらないときは管理者に伝えてください |
| 「処理に失敗」になった | 文書の画面で理由を見て「再処理」。同じ失敗が続くときは管理者に伝えてください |
| 「保存のみ」になった | 文字を取り出せない形式です（[扱えるファイル](files.md#扱えるファイル)）。PDF に変換してアップロードすると読める場合があります |
| 写真の文字がおかしい | 「取り出したテキスト」で確かめ、「このページを読み直す」（[読み取りを確かめる](organize.md#読み取りを確かめる直す)）。手書きや斜めの写真は苦手です |
| 検索で見つからない | [検索の「見つからないとき」](search.md#見つからないとき) |
| アップロードが止まる | 回線が戻れば続きから再開します。ページを読み込み直したら、同じファイルを選び直すと続きから送ります |
| 「容量の上限（…）を超えるため保存できません」と出る | 要らないファイルを消し、ゴミ箱も空にしてください（過去の版も容量に数えます）。足りなければ管理者に相談してください |
| 消したファイルを戻したい | 左のメニューの「ゴミ箱」→「元に戻す」（[ゴミ箱](files.md#ゴミ箱)）。日数を過ぎたものは戻せません |
| 上書きする前の中身に戻したい | 文書の画面の「過去の版」→「この版に戻す」（[過去の版](files.md#過去の版)） |
| ほかの人に見せたい | [共有](sharing.md) |
| 共有リンクを相手が開けない | 期限・回数の上限・パスワードを確かめる。外の人は、サーバーがインターネットから届かないと開けません |
| 「アクセスが多すぎます」と出る | 短い時間に多く開きすぎています。しばらく待つと戻ります |
| ログインできない | [ログインと安全の「ログインできなくなったとき」](login.md#ログインできなくなったとき) |
| パスキーが使えない | IP アドレスではなく名前の URL で開いているか確かめてください（[パスキー](login.md#パスキーを追加する)） |
| 「URL を追加」・要約・「質問に答える」が出ない | 管理者が有効にしていない機能です |
| 管理の画面（`/admin`）が開けない | 管理者だけの画面です。管理者でも、家の外からは開けないようにしてあります（Tailscale などで中から開いてください） |

ここに無いことは管理者に聞いてください。管理者は [管理者ガイドの困ったとき](../admin/troubleshooting.md) も見られます。
