# 整理する

## タグ

ファイルにタグ（例 `経理`・`2026`）を付けると、`tag:経理` で絞り込めます。

- 文書の画面のタグの欄で付け外しします
- 一覧で複数を選ぶと、下のバーの「タグ」でまとめて付ける・外すことができます
- 左のメニューの **「タグ」** で、自分のファイルのタグの一覧と件数を見られます。名前を変える（既にある名前にすると 1 つにまとまります）・外すこともできます

## 置き場所とタグの候補

似ている文書から、**置くフォルダ** と **付けるタグ** の候補を出します。候補は提案だけで、移動やタグ付けはボタンを押したときに行います。

- **Inbox**・共有リンクで受け取った文書・マイファイルの直下に置いた文書には、文字の読み取りが終わると候補を作ります。Inbox の一覧には文書ごとのおすすめのフォルダが出て、「移動」で動かせます。選んだ文書をまとめて移動することもできます
- それ以外の文書は、文書の画面を開くと **「整理の候補」** の欄に出ます
- 候補にするのは **自分のフォルダ** だけです（ほかの人のフォルダは候補にしません）
- 却下したタグの候補は、同じ文書には二度と出しません。取り消すには「設定」→「整理の補助」→ **「却下した候補の一覧」**

「設定」→「整理の補助」で、候補を出すかどうかと、自動で行うことを選べます。

| 設定 | 内容 |
|---|---|
| フォルダの候補を出す / タグの候補を出す | 候補を出すかどうか |
| おすすめのフォルダへ自動で移動する | Inbox と共有リンクで受け取った文書で、確かさが高いときだけ。元に戻せます |
| 似た文書の多くに付いているタグを自動で付ける | |
| 自動で作った要約を表示する | 要約を使っているときだけ出ます |

## 要約

**管理者が有効にしたときだけ** 使えます。

サーバーの中の小さな AI が、文書ごとに 2〜3 文の要約と、新しいタグの候補（種類・分野・主題。例「請求書」「地理」）を作ります。要約は文書の画面と検索結果に出て、検索の対象にもなります。文書の中身はサーバーの外に送りません。

- 要約は、ほかの処理が無いときに 1 件ずつ作ります。すぐには出ないことがあります
- 合わないときは、文書の画面の「整理の候補」の **「要約とタグをやり直す」** で作り直せます（一覧で複数を選んで、まとめてやり直すこともできます）
- **「要約を直す・消す」** で、手で書き直したり、その文書では出さないようにしたりできます。「自動の要約に戻す」で元に戻ります
- 小さな AI なので誤りがありえます。大事なことは本文で確かめてください

## 読み取りを確かめる・直す

画像やスキャンした PDF の文書の画面では、**「取り出したテキスト」** で読み取った文字を見られます。

- **「読み取った位置を画像に重ねて表示」** で、どこをどう読んだかを画像の上で確かめられます
- 一部のページだけおかしいときは、ページごとの **「このページを読み直す」** で、そのページだけを読み直せます。PDF は、埋め込みの文字を使わずに画像として読むこともできます
- 全体を読み直すときは「再処理」。一覧で複数を選んで、まとめて再処理することもできます
- 文書の画面は、読み取りや要約が終わると自動で新しくなります

手書きの文字・表や段組みの構造は、うまく読めないことがあります。
