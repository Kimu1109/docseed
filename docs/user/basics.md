# はじめに

## 開く

管理者から教わった URL（例 `https://docseed.example.com/`）をブラウザで開き、ユーザー名とパスワードでログインします。

- 初めて開いたときに「この接続ではプライバシーが保護されません」などの警告が出ることがあります。管理者が手元の証明書を使っている場合です。続けてよいかは管理者に確かめてください
- ログイン画面の「ログインしたままにする（14 日間）」を付けないと、ブラウザを閉じるか 12 時間でログアウトします
- パスキーや確認コードの設定は [ログインと安全](login.md)

## 画面の見方

| 場所 | 内容 |
|---|---|
| 上の検索欄 | どの画面からでも検索できます（`/` キーで移動） |
| 左のメニュー | **マイファイル**（自分のフォルダ）・**お気に入り**・**検索**・**共有されたフォルダ**（ほかの人から分けてもらったもの）・**タグ**・**ゴミ箱**・**ヘルプ**（このガイド）。管理者には **管理** も出ます |
| 左のメニューの下 | 文字の読み取りを待っている自分のファイルの数（「処理中: N」）と、使っている容量 |
| 右上のメニュー | **設定**・**セキュリティ（ログイン方法）**・ログアウト |

### ファイルの状態

アップロードしたファイルは、サーバーが中の文字を読み取ってから検索できるようになります。一覧の「状態」の列に出ます。

| 表示 | 意味 |
|---|---|
| 処理待ち | 順番を待っています。数が多いと時間がかかります |
| 処理中 | 読み取っています（PDF はページの進み具合も出ます） |
| 検索できます | 終わりました。中の文字で探せます |
| 保存のみ | 文字を取り出せない形式です。保存・共有・ダウンロードはできます（[扱えるファイル](files.md#扱えるファイル)） |
| 処理に失敗 | 読み取れませんでした。文書の画面で理由を見て、「再処理」を試してください |

状態は自動で新しくなります。画面を開き直す必要はありません。

## スマホで使う

スマホのブラウザで開くと、スマホ用の画面になります（アプリを入れる必要はありません）。

- 画面の下に **ファイル・お気に入り・検索・共有・メニュー** のタブがあります。「メニュー」でタグ・ゴミ箱・設定などを開きます
- 右下の **＋** から、ファイルのアップロード・**カメラで撮ってアップロード**・新しいフォルダ・URL の追加ができます
- 行を **長押し** すると選択が始まります。選択中は行をタップして足す・外す、下のバーで移動・タグ・ゴミ箱などをまとめて行えます
- PDF は「全画面で開く」で全ページを見られます（iPhone の埋め込みの表示では 1 ページ目しか出ないことがあるため）
- 検索の絞り込みは「絞り込み」ボタンで開きます

## 画面の色

端末の設定に合わせて **ダークモード** になります。「設定」→「画面の色」で、ライト・ダークに固定することもできます。

## 画面の言語

画面は **日本語** と **英語（English）** で使えます。はじめはブラウザの言語の設定に合わせます。「設定」→「画面の言語」で、日本語・English に固定することもできます。ログインの画面では、下の「日本語 · English」で切り替えられます。

ヘルプの文書は日本語だけです。

## キーボード操作

`?` で一覧を出せます。文字を入力している間は使えません。

| キー | 動き |
|---|---|
| `/` | 検索欄へ |
| `?` | キーボード操作の一覧 |
| `g` → `m` / `f` / `s` / `t` / `d` / `h` | マイファイル / お気に入り / 共有されたフォルダ / タグ / ゴミ箱 / ヘルプ（管理者は `g` → `a` で管理） |
| `s` | 今のファイル・フォルダをお気に入りに入れる・外す |
| `j` `k`（`↓` `↑`） | 一覧・検索結果で下・上へ（一覧では Shift で範囲を選ぶ） |
| `Enter` | 開く |
| `x` | 選択に足す・外す |
| `Ctrl` + `A` / `Esc` | すべて選ぶ / 選択を外す |
| `F2` | 名前を変更 |
| `Delete` | ゴミ箱に移動 |
| `u` / `n` | アップロード / 新しいフォルダ |

選ぶ・名前の変更・削除・アップロードは、編集できるフォルダだけで使えます。
