# 共有

フォルダやファイルの画面の **「共有」** から設定します。

| 相手 | 方法 | できること |
|---|---|---|
| docseed のほかのユーザー | フォルダの「共有」→「ユーザー」 | **閲覧のみ** か **編集できる**。下のフォルダにも引き継がれます |
| docseed のアカウントが無い人 | 「共有」→「リンク」→「リンクを作成」 | 見てもらう・ダウンロードしてもらう（**閲覧・ダウンロード**）か、ファイルを送ってもらう（**受け取り用**） |

## ほかのユーザーとフォルダを分け合う

1. フォルダの「共有」→「ユーザーを選ぶ」で相手を選ぶ
2. 「閲覧のみ」か「編集できる」を選んで「追加」

- 相手の左のメニューの **「共有されたフォルダ」** に出ます
- 共有できるのは **フォルダ** です。ファイルの見え方は、置いてあるフォルダの共有に従います
- 追加・変更・外すのは、フォルダの **所有者** だけができます
- 共有したフォルダに相手が置いたファイルも、容量は所有者の分として数えます

## リンクで渡す（閲覧・ダウンロード）

「リンクを作成」で URL を作り、「コピー」して相手に送ります。相手はログインせずに開けます。

| 項目 | 内容 |
|---|---|
| 有効期限 | 1 日・7 日・30 日・無期限（無期限はおすすめしません） |
| パスワード | 任意（4 文字以上）。リンクとは別の方法で伝えてください |
| ダウンロード回数の上限 | 任意 |

- フォルダのリンクでは、相手は中身を一覧し、まとめて ZIP でダウンロードすることもできます（2GB まで）
- 写真に撮影場所が入っていると、共有の画面に「位置情報（撮影場所）を含む写真が N 件あります」と出ます。受け取った人は撮影場所を読み取れます

## ファイルを送ってもらう（受け取り用）

フォルダの「リンクを作成」で種類を **「受け取り用」** にすると、相手がそのフォルダにファイルを送れるリンクになります。相手には **フォルダの中身は見えません**。

- 期限は 30 日までです（無期限にはできません）
- 届いたファイルには、置き場所とタグの候補が出ます（[整理する](organize.md#置き場所とタグの候補)）。管理者が通知を設定していれば、届いたことが知らされます
- 送れる量には上限があります（既定で 1 リンク 10GB まで、全体で 24 時間に 20GB まで、サーバーの空きが少ないときは止まります）

## リンクを止める

- 共有の画面の「無効にする」で、すぐに開けなくなります
- 自分が作ったリンクの一覧は「設定」→「自分が作った共有リンク」にあります
- リンクを作った人がそのフォルダの権限を失うと、そのリンクは自動で使えなくなります

## 外の人にリンクを渡すときの注意

外の人がリンクを開くには、docseed にインターネットから届く必要があります。家の中や Tailscale の中だけで使っている場合は、外からは開けません。どこから開けるかは管理者に確かめてください（管理者向け: [インターネットに公開する](../admin/exposure.md)）。
